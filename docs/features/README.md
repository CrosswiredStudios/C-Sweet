# Feature proposals and product specifications

This section contains reviewable feature documentation: product intent, customer
journeys, architecture, commercial models, examples, and decisions. A document here
does not establish that the feature is implemented or available.

Use [implementation documentation](../implementation/README.md) for existing
implementation maps and delivery work. Feature proposals can reference those maps
without becoming an implementation checklist.

| Feature | Status | Start here |
|---|---|---|
| Hosted platform and hybrid Offices | Draft for review | [Overview and reading guide](hosted-platform/README.md) |

Within each feature, distinguish **agreed direction**, **proposed design**,
**observed implementation**, and **open decisions**. Keep diagrams and examples
consistent with the decision register; use source symbols rather than line numbers.
