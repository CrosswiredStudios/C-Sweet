## Cause and implementation

`TechnicalReviewJson.ReadAsync` previously accepted at most 16,000 response characters and one correction. `BranchDiffTechnicalReview.ValidateFinal` stopped on the first invalid field: summary at 1,500 characters, criterion evidence/resolution reason at 500. For `VGCD352DE8BC-15`, Victor returned a 1,662-character summary and 621-character criterion evidence; its correction shortened the summary to 1,073 but left 567 characters of evidence. Both responses proposed approval without blockers, but neither constituted an accepted decision.

SDK **4.6.3** raises requirements, synthesis input and model response limits to **128,000 characters**. Summary, evidence, reason, problem, correction and observation/question fields allow **16,000 characters**; paths allow **2,048**. Up to 16 blockers and 16 observations/questions are allowed per response, with 1–512 distinct reviewed offsets per resolution/criterion. Transport diff pages remain bounded at 12,000 characters, preserving existing contiguous coverage and checkpoint identities.

`TechnicalReviewJson` adds matching bounds to the generated response schema, collects text-bound errors with exact JSON paths and measured lengths, rejects duplicate fields and invalid collection elements, and permits three correction calls after the initial response. Correction history retains the original evidence and only the latest failed response. Exhaustion explicitly identifies a C-Sweet review-processing issue for management escalation. Invalid reports never authorize integration or silently truncate accepted evidence. Configured platform token ceilings remain authoritative; Victor's installation currently permits 32,000 output tokens and 256,000 context tokens.

`BranchDiffTechnicalReview.ValidateFinal` collects criterion-coverage, finding-identity, disposition, citation and verdict-consistency errors together. Every reused page is reauthorized, hash checked and validated; final current-item/current-candidate reads still fence changed sources, targets and planning. The saved-page policy remains `bounded-review-2026-10-15` because the accepted old page format and substantive evidence remain compatible.
